## 2. Descripción del Servicio

Senda es un cliente de productividad y gestión de correo electrónico, calendario, tareas y notas adhesivas desarrollado con arquitectura **Local-First**. La Aplicación permite:

- Conectar y sincronizar cuentas de correo mediante protocolos estándar IMAP/SMTP y la API oficial de Google OAuth 2.0 (Gmail, Google Calendar y Google Tasks).
- Gestionar correo electrónico, redactar mensajes, organizar etiquetas y carpetas, y aplicar filtros de búsqueda avanzada.
- Administrar eventos de calendario, listas de tareas y notas adhesivas en una pizarra interactiva.
- Utilizar herramientas de productividad con asistencia de inteligencia artificial mediante el copiloto integrado (Elio) y la API de Google Gemini.
